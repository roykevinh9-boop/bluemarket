# BlueMarket

Prototipo académico de un supermercado en línea. Incluye catálogo, ofertas,
carrito y un recorrido de demostración con los perfiles de cliente,
administrador y repartidor.

## Abrir la tienda

Abre `index.html` en el navegador. El archivo reúne el catálogo y las imágenes.
Los pedidos simulados se guardan localmente en el navegador.

El ZIP contiene la versión editable con sus archivos HTML, CSS, JavaScript e imágenes.
